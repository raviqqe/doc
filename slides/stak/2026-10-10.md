# Stak Scheme

- A bytecode compiler and virtual machine (VM) for Scheme
  - The compiler is written in Scheme.
  - The VM is written in Rust.
- It implements the R7RS-small standard.

# Floating-point numbers

---

# Floating-point number literals

- Bytecode used to pack a sign, an exponent, and a mantissa into one integer.
  - The integer must fit in the 52-bit mantissa of `f64`.
    - Some VMs represent all numbers as `f64`.
  - Mantissas were limited to 38 bits (~11 decimal digits).
- Now, a mantissa is encoded as a separate integer.
  - Literals keep their full 53-bit mantissas.

# Library load paths

- `(import (foo bar))` loads `foo/bar.sld` in library load paths.
- `-I` (prepend) and `-A` (append) options from SRFI 138
  - Both in the `stak` and `stak-compile` commands
- `include` in libraries resolves paths relative to their files.
- Circular imports are detected.

---

# Library load paths

```scheme
; lib/foo/bar.sld
(define-library (foo bar)
  (export hello)
  (import (scheme base) (scheme write))
  (begin
    (define (hello)
      (display "Hello, world!")
      (newline))))
```

```scheme
; main.scm
(import (foo bar))

(hello)
```

```sh
stak -I lib main.scm
```

# R7RS compatibility

- `include-library-declarations`
- `cond-expand` with `(library ...)` checks available libraries.
  - It used to check a fixed list of library names.
- `exit` with integers
- Reader (on `main`)
  - Datum comments
  - Hexadecimal characters

```scheme
(write '(1 #;2 3)) ; -> (1 3)
(write-char #\x3bb) ; -> λ
```

| Program                                  | v0.12.14      | `main`         |
| ---------------------------------------- | ------------- | -------------- |

# Compiler on Gauche

- The compiler is written in portable R7RS.
  - CI compiles all Scheme files with Chibi Scheme, Gauche, Guile, and Stak Scheme, and compares their bytecode byte by byte.
- Gauche crashed on the compiler for a year.
  - A bug in its `inline-locals` optimization with nested closures
  - [Reported](https://github.com/shirok/Gauche/issues/1333) and fixed upstream on October 4
  - CI uses `gosh -fno-inline-locals` until the next release.

# Big integers?

- [Investigated with AI](https://raviqqe.com/doc/ai/stak/big-integer)
  - Bignums as ribs with an unused type tag
  - Arithmetic implemented in Scheme
- Options
  - An opt-in `(stak bignum)` library: zero cost for other programs
  - Transparent promotion with overflow checks in Scheme: 1.6-2.5x slower arithmetic
  - Primitives calling Scheme procedures on overflow: no cost on the fast path
- The numeric tower is still the final boss.
